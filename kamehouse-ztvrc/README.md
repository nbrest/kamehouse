# ZtvRc Module:

This module handles the following functionality:

* Start and stop a ztv player in the current server
* Send commands to the currently running ztv player through ztv's http api
* Get the status of the running instance of a ztv player to be rendered in the UI
* Get the currently running playlist to be rendered in the UI
* Register and unregister ztv players (both in localhost and remote) in kamehouse to connect to their http API

## Stream videos to chromecast:

### VLC
- In VLC player > Playback > Renderer > Select chromcast device to stream to
